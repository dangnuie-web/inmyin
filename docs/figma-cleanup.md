# 피그마 정리 가이드

일러스트레이터에서 넘어오신 분이 가장 헷갈리는 부분만 골라 순서대로 적었습니다. 위에서부터 하나씩 하시면 됩니다. 전부 다 하실 필요는 없고, **1단계와 2단계만 해도 클로드 코드가 훨씬 정확해집니다.**

일러스트레이터와 대응해서 읽으시면 빠릅니다.

| 일러스트레이터 | 피그마 |
| --- | --- |
| 아트보드 | 프레임 (Frame) |
| 레이어 패널 | 왼쪽 레이어 패널 (같은 개념) |
| 심볼 | 컴포넌트 (Component) |
| 그래픽 스타일 / 색상 견본 | 변수 (Variables) + 스타일 |
| 그룹 | 그룹 또는 프레임 |

---

## 1단계 — 이름 규칙 (30분)

지금 파일은 `2. My-2.INVENTORY-ITEM 활영-편집` 처럼 이름이 제각각이고 오타도 섞여 있습니다. 이름이 곧 화면 ID가 되니 여기부터 맞춥니다.

**규칙: `화면ID · 이름` 한 가지로만 씁니다.**

```
M-04 · 인벤토리 상세
M-05 · 짐싸기
M-06 · 아이템 촬영
M-07 · 아이템 편집
M-08 · 아이템 정보 입력
```

`docs/screens.md`의 표를 그대로 쓰시면 됩니다. 웹 버전은 뒤에 `(웹)`을 붙입니다.

```
H-01 · Home 아이템 (웹)
```

**바꾸는 법**: 레이어 패널에서 이름 더블클릭 → 입력. 여러 개를 한 번에 바꾸려면 여러 레이어를 선택하고 `Cmd+R`(맥) / `Ctrl+R`(윈도우).

체크리스트

- [ ] 오타 고치기 — `활영` → `촬영`
- [ ] 중복 이름 없애기 — 같은 이름 프레임이 3개씩 있습니다. 실제로 다른 상태면 `M-09 · INMYIN 에디터 (빈 캔버스)`처럼 상태를 뒤에 붙이고, 안 쓰는 건 지웁니다
- [ ] `2.`, `4.` 같은 앞 번호는 화면 ID로 대체
- [ ] 웹 버전에 `(웹)` 붙이기

---

## 2단계 — 페이지 나누기 (10분)

지금 전부 `Page 1`에 있습니다. 왼쪽 위 **페이지** 영역에서 `+`를 눌러 추가하고, 프레임을 드래그해 옮깁니다.

```
📄 01 모바일 — 온보딩
📄 02 모바일 — Home
📄 03 모바일 — My
📄 04 모바일 — Like
📄 05 웹
📄 99 보관함   ← 안 쓰는 옛날 시안
```

버리기 아까운 시안은 지우지 말고 `99 보관함`으로 옮기세요. 작업 페이지가 깨끗해지는 게 목적입니다.

---

## 3단계 — 변수 등록 (1시간)

여기부터가 코드로 바로 넘어가는 부분입니다. 색과 간격에 이름을 붙여두면 그대로 Tailwind 토큰이 됩니다.

**만드는 법**: 오른쪽 패널 맨 아래 **Local variables** → `+` → 컬렉션 만들기.

### 색

```
color/bg          배경
color/surface     카드·패널 배경
color/border      선
color/text        본문 글자
color/text-muted  흐린 글자
color/primary     주 색 (버튼, 강조)
color/like        하트 색
```

### 간격

4의 배수로 통일합니다. 지금 여백이 13px, 17px 같은 값이면 12px, 16px로 맞추세요.

```
space/1 = 4     space/2 = 8     space/3 = 12
space/4 = 16    space/6 = 24    space/8 = 32
```

### 모서리

```
radius/sm = 8    radius/md = 12    radius/lg = 20    radius/full = 9999
```

### 글자

변수 대신 **텍스트 스타일**로 만듭니다. 오른쪽 패널 Typography 옆 `⋮⋮⋮` → `+`.

```
text/title      20 / Bold
text/body       15 / Regular
text/caption    13 / Regular
text/label      13 / Medium
```

체크리스트

- [ ] 쓰고 있는 색을 다 모아보고 비슷한 건 합치기 (회색이 5개면 2~3개로)
- [ ] 위 이름으로 변수 등록
- [ ] 여백을 4의 배수로 정리
- [ ] 텍스트 스타일 4~6개 만들기

---

## 4단계 — 컴포넌트로 묶기 (2시간)

프레임마다 복붙해 넣은 것들을 하나로 묶습니다. 일러스트레이터 심볼과 같은 개념입니다.

**만드는 법**: 묶을 요소들을 선택 → `Cmd+Option+K`(맥) / `Ctrl+Alt+K`(윈도우).

이 앱에서 꼭 필요한 것 7개:

| 컴포넌트 | 변형(Variants) |
| --- | --- |
| 아이템 카드 | 그리드 / 리스트 |
| 인벤토리 칸 | 빈 칸 / 아이템 있음 / 인벤토리 있음 / 잠김 |
| 하단 탭 | Home 선택 / My 선택 / Like 선택 |
| 팔로우 버튼 | 팔로우 / 팔로잉 |
| 하트 버튼 | 꺼짐 / 켜짐 |
| 카테고리 칩 | 기본 / 선택됨 |
| 상단바 | 뒤로가기 있음 / 없음 |

**변형 만드는 법**: 컴포넌트 선택 → 오른쪽 패널 `Variants`의 `+`. 상태별로 따로 만들지 말고 한 컴포넌트 안에 넣으세요. 코드에서도 `<ItemCard variant="grid">` 한 줄이 됩니다.

체크리스트

- [ ] 위 7개 컴포넌트 만들기
- [ ] 각 프레임의 복붙된 요소를 컴포넌트 인스턴스로 교체
- [ ] 컴포넌트 안의 색·여백을 3단계 변수로 바꾸기

---

## 5단계 — 넘기기 전 마지막 확인 (10분)

- [ ] 프레임 크기가 통일되어 있는지 — 모바일 390×844, 웹 1440 기준
- [ ] Auto layout이 걸려 있는지 (`Shift+A`). 이게 걸려 있어야 코드의 flex/gap으로 바로 번역됩니다
- [ ] 텍스트가 이미지로 붙어 있지 않은지 — 글자는 텍스트 레이어여야 읽힙니다
- [ ] 개발자 모드(Dev Mode)로 한 화면 열어보고, 오른쪽에 나오는 값이 말이 되는지 확인

---

## 다 하고 나면

공유 링크에 **"보기" 권한 + Dev Mode 접근**을 켜서 주시면, 클로드 코드가 색·여백·폰트 값을 직접 읽어 코드에 넣을 수 있습니다.

정리 중에 막히는 부분이 있으면 그 화면 스크린샷 한 장 주세요. 그 부분만 같이 보겠습니다.
