## GraphQL은 안 해도 되나요?

**안 해도 됩니다.** 오히려 하지 마세요.

GraphQL은 "데이터를 요청하는 방식" 중 하나입니다. Supabase는 이미 이런 식으로 데이터를 가져올 수 있게 해줘요.

```ts
// 내 아이템 전부 가져오기 — 이게 끝입니다
const { data } = await supabase
  .from('items')
  .select('*')
  .eq('user_id', userId)
```

GraphQL을 얹으면 여기에 스키마 정의, 쿼리 언어, 서버 설정이 더 붙습니다. 배울 게 늘어나고 코드가 길어지는데, 혼자 만드는 앱에서는 얻는 게 없습니다.

GraphQL이 빛나는 건 **화면이 수십 개이고 팀이 여럿이라, 각 화면이 필요한 데이터만 골라 받아야 할 때**입니다. 나중에 그런 규모가 되면 그때 붙여도 늦지 않아요.

> Supabase에도 GraphQL 기능이 있긴 합니다(`pg_graphql`). 켜지 마세요. 켜는 순간 두 가지 방식이 섞여서 헷갈립니다.

## 아이폰에서 써보려면

결론부터: **지금 단계에서 앱스토어는 필요 없습니다.** 오늘 당장 무료로 아이폰에 설치할 수 있어요.

### 방법 1 — PWA (지금 이걸로 가세요)

1. Vercel에 배포하면 `inmyin.vercel.app` 같은 주소가 나옵니다
2. 아이폰 **사파리**로 그 주소를 엽니다 (크롬 말고 사파리여야 합니다)
3. 하단 공유 버튼 → **홈 화면에 추가**
4. 홈 화면에 아이콘이 생기고, 누르면 주소창 없이 앱처럼 열립니다

| | |
| --- | --- |
| 비용 | 무료 |
| 심사 | 없음 |
| 걸리는 시간 | 배포 후 1분 |
| 업데이트 | 코드 고치고 배포하면 끝. 재설치 불필요 |

친구에게 링크를 보내면 친구도 같은 방식으로 설치할 수 있습니다. 앱스토어 없이도 배포가 되는 셈이에요.

**PWA의 한계 (iOS 기준)**

- 설치 배너가 안 뜹니다. "사파리에서 공유 → 홈 화면에 추가"를 직접 알려줘야 함
- 푸시 알림은 iOS 16.4 이상 + 홈 화면에 설치된 상태에서만 옴
- 카메라는 됩니다. 다만 기본 카메라 앱만큼 매끄럽진 않음
- 앱스토어 검색으로는 찾을 수 없음

### 방법 2 — 앱스토어 (나중에)

| | |
| --- | --- |
| 비용 | **연 99달러** (Apple Developer Program) |
| 심사 | 있음. 보통 1~3일, 반려되면 고쳐서 재제출 |
| 필요한 것 | 맥 + Xcode |

**주의할 점이 하나 있습니다.** 웹사이트를 그대로 감싸서 올리면 애플이 반려하는 경우가 많습니다. "웹에서 되는 걸 왜 앱으로 만드느냐"는 기준(App Store 심사 지침 4.2)이 있어요. 카메라, 푸시, 위젯 같은 앱다운 기능이 들어가 있어야 통과가 수월합니다.

다행히 **지금 코드를 그대로 쓰면서** 나중에 Capacitor라는 도구로 감싸 앱으로 만들 수 있습니다. 처음부터 앱으로 만들 필요가 없어요.

### 그래서 순서는

```
1단계  Vercel 배포 → 사파리 → 홈 화면에 추가 → 본인이 써보기   (지금)
2단계  친구 몇 명에게 링크 공유                                (곧)
3단계  사람이 붙고 푸시가 꼭 필요해지면 → Capacitor → 앱스토어   (나중에)
```

3단계를 지금 고민하지 마세요. 만들어놓고 본인이 안 쓰는 앱이 되는 경우가 훨씬 많습니다.

Sources: [Apple Developer Program 가입](https://developer.apple.com/programs/enroll/)
