# INMYIN — 제품 정의

## 한 줄

내가 가진 것을 사진으로 찍어 가상의 창고에 넣어두고, 한눈에 보고 남에게 보여주는 앱.

## 왜

물건을 격자 칸에 채워 넣는 게임 인벤토리의 은유를 그대로 쓴다. 등록은 사진 한 장에서 시작하고, 배경을 자동으로 지워 물건만 남긴 썸네일이 칸에 꽂힌다. 모인 아이템은 혼자 관리용으로 쓸 수도, 공개해서 다른 사람에게 보여줄 수도 있다.

## 누가 언제 쓰는가

| 상황 | 쓰는 방식 | 중요한 기능 |
| --- | --- | --- |
| 취향 공유 | 좋아하는 물건을 공개 인벤토리에 모아 친구에게 보여줌 | INMYIN 게시물, 팔로우, 프로필 공유 |
| 물건 관리 | 내가 가진 것을 한눈에 보고 중복 구매를 막음 | 인벤토리 그리드, 카테고리, 개수 |
| 이사 | 짐을 상자 단위로 기록해 어디에 뭐가 들었는지 추적 | 인벤토리 중첩, 짐싸기 |
| 냉장고·옷장 | 재료와 옷을 찍어두고 보유 현황 확인 | 유통기한, 획득날짜 필드 |

주 사용자는 정리와 기록을 좋아하고, 자기 취향을 남에게 보여주는 데 거리낌이 없는 사람이다. 댓글은 없고 좋아요와 팔로우만 있어서, 대화보다는 **보여주기와 구경하기** 중심의 느슨한 커뮤니티다.

## 확정된 규칙

| 항목 | 결정 |
| --- | --- |
| 앱 이름 | INMYIN |
| 인벤토리 확장 | 결제. 베이직 / 프리미엄 2단계 |
| 로그인 | 구글·카카오 간편로그인 + 이메일 가입 모두 |
| 카테고리 | 유저가 만들지 않는다. 추천 인벤토리에 내장된 고정 카테고리만 |
| 비공개 아이템 | 남이 볼 때 아예 안 보인다 (칸째로 빠짐) |
| 인기 순위 | 좋아요 수 + 시간 창. 인기 / 추천 두 필터로 분리 |
| 데스크톱 | 아이템 등록(촬영)만 불가. 나머지는 모두 가능 |
| 신고·차단 | 차단은 2단계, 신고는 추후 과제 |
| 짐싸기 | 다중 선택 없음, 되돌리기 없음. 받는 쪽이 꽉 차면 알림 |
| 아이템 재사용 | 아이템은 불러올 수 없다. 인벤토리는 다른 인벤토리에 담을 수 있다 (2겹까지) |
| 칸 배치 | 새 아이템은 항상 다음 빈 칸. 기존 아이템을 밀어내지 않는다 |
| 백엔드 방식 | Supabase 클라이언트로 직접. GraphQL·별도 API 서버 없음 |
| 배포 | PWA 우선. 앱스토어는 나중에 (아래 배포 계획) |
| 유통기한 알림 | 추후 과제 (설정 › 알림) |
| 삭제된 아이템 | 게시물 이미지는 남고 링크만 죽는다 |
| 이미지 보관 | 원본 + 배경제거본 둘 다 |

## 추천 인벤토리와 고정 카테고리

`lib/categories.ts`에 상수로 둔다. 새 인벤토리를 만들 때 이 4종을 먼저 보여준다.

| kind | 이름 | 내장 카테고리 |
| --- | --- | --- |
| `closet` | 옷장 | 상의, 하의, 신발, 모자, 가방 |
| `fridge` | 냉장고 | 고기, 야채, 반찬, 냉동, 조미료 |
| `home` | 집 | 거실, 침실, 화장실 |
| `supplies` | 생활용품 | 청소, 세탁, 소모품 |
| `custom` | (유저가 이름 지정) | 없음 |

`custom` 인벤토리는 카테고리가 없다. 그 안의 아이템은 카테고리 없이 등록되고, Home과 Like 탭의 카테고리 필터에 잡히지 않는다. 생성 화면에 이 점을 한 줄로 안내한다.

## 인기와 추천 산식

`lib/ranking.ts`.

| 필터 | 대상 | 정렬 |
| --- | --- | --- |
| 인기 | 전체 유저 | 최근 24시간 좋아요 수 |
| 추천 | 누적 좋아요 100 미만인 유저 | 최근 1시간 좋아요 수 |

기준선 100은 상수로 빼둔다. 사람이 모이면 조정한다.

## 배포 계획

| 단계 | 방식 | 비용 | 언제 |
| --- | --- | --- | --- |
| 1 | Vercel 배포 + 사파리 "홈 화면에 추가" | 무료 | 1단계 끝나면 바로 |
| 2 | 같은 링크를 친구에게 공유 | 무료 | 2단계 끝나면 |
| 3 | Capacitor로 감싸서 앱스토어 | 연 99달러 | 사람이 붙고 푸시가 꼭 필요해지면 |

**앱스토어는 처음부터 고려하지 않는다.** 웹을 그대로 감싸 올리면 애플 심사 지침 4.2(minimum functionality)로 반려되는 경우가 많고, 지금 단계에서 얻을 게 없다. 지금 코드를 그대로 쓰면서 나중에 감쌀 수 있으니 미루면 된다.

### iOS PWA 제약 (기획 시 감안할 것)

- 설치는 사파리 "홈 화면에 추가"로만 된다. 안드로이드처럼 설치 배너가 뜨지 않으므로, 설치 안내 화면을 따로 만들어야 한다
- 푸시 알림은 iOS 16.4 이상 + 홈 화면에 설치된 상태에서만 온다
- 카메라는 동작하지만 기본 카메라 앱만큼 매끄럽지 않다
- 앱스토어 검색으로는 찾을 수 없다. 초기 유입은 링크 공유뿐이다
