# 화면 정의

피그마 파일 `인벤토리` 기준. 고유 화면 31개. 모바일 프레임이 기준이고, 같은 화면의 웹(데스크톱) 버전이 별도 프레임으로 존재한다.

## 하단 탭

```
1. Home (커뮤니티)   2. My   3. Like (북마크 → Like로 이름 변경)
```

M-04 · 인벤토리 상세
M-04 · 인벤토리 상세 (웹)

## A-01 · 로그인

로그인하지 않은 사람이 앱에 들어오면 가장 먼저 보는 화면. 주소는 `/login`.

- 로고
- Google로 로그인 / Kakao로 로그인 — 처음이면 A-03, 아니면 홈으로
- 글자 링크 두 개: 이메일 가입 → A-02, 이메일 로그인 → A-01a
- 맨 아래: 이용약관 · 개인정보 취급방침 · 문의 메일
- 이미 로그인한 사람이 오면 홈으로 돌려보낸다

## A-01a · 이메일 로그인

주소는 `/login/email`. 피그마 프레임은 없고 A-02와 같은 모양으로 만든다.

- 이메일 + 비밀번호 (눈 아이콘으로 보기/숨기기) → 로그인
- 비밀번호 칸 아래에 글자 링크 **비밀번호를 잊으셨나요?** → A-04
- 아래에 이메일 가입(A-02), 다른 방법으로 로그인(A-01)

## A-02 · 가입

이메일 가입 전용. 구글·카카오는 가입 화면 없이 A-01에서 바로 A-03으로 간다. 주소는 `/signup`.

1. 이메일 입력 → **인증번호 전송** → 메일로 온 숫자를 입력 → **확인**. 남은 시간 3:00 표시, 다시 보내기는 60초 뒤부터
   - 맞으면 "인증번호가 확인되었습니다."가 뜨고 시간 표시가 사라지며 이메일·인증번호 칸이 잠긴다
2. 비밀번호 입력 (8자 이상, 눈 아이콘으로 보기/숨기기) — 인증번호를 확인한 뒤에 입력할 수 있다
3. 약관 동의 — "모두 동의합니다" + 개별 항목. 항목은 `lib/terms.ts`
4. **가입하기** → 비밀번호 + 약관 동의 저장 → A-03

인증번호를 보내기 전에는 인증번호 칸과 약관이 보이지 않는다 (가입1 → 가입2 프레임).

## A-03 · 프로필 만들기

첫 로그인 직후 한 번만 나온다. 주소는 `/onboarding`. 이걸 끝내야 `User` 행이 생긴다.

- 닉네임 — 구글·카카오 이름이 있으면 미리 채워둔다
- 아이디(`handle`) — 프로필 주소 `/u/아이디`가 된다. 영소문자·숫자·`_`, 3~30자, 중복 불가
- 구글·카카오로 들어와 아직 약관에 동의한 적 없는 사람에게는 여기서 약관 동의를 받는다
- **등록하기** → 홈

프로필이 없는 사람이 다른 화면으로 가려 하면 여기로 돌려보낸다.

## A-04 · 비밀번호 재설정

이메일로 가입한 사람이 비밀번호를 잊었을 때. 주소는 `/reset-password`. A-02와 같은 모양에서 약관만 뺀다.

안내문: "가입한 이메일을 입력하면 본인인증 후 비밀번호를 재설정할 수 있습니다."

1. 이메일 입력 → **인증번호 전송** → 메일로 온 숫자를 입력 → **확인**. 남은 시간·다시 보내기·확인 뒤 잠금은 A-02와 같다
2. **새 비밀번호** 입력 (8자 이상, 눈 아이콘으로 보기/숨기기) — 인증번호를 확인한 뒤에 입력할 수 있다
3. **비밀번호 변경하기** → 새 비밀번호 저장 → 로그인된 상태로 홈

- 가입하지 않은 이메일이면 메일을 보내지 않고 "가입하지 않은 이메일입니다."라고 바로 알려준다. 계정을 새로 만들지 않는다
- 가입한 이메일이 기억나지 않는 사람을 위해 맨 아래에 안내를 둔다: 구글·카카오로 가입했다면 로그인 화면의 해당 버튼으로, 그래도 못 찾으면 문의 메일로
- 아이디(`handle`)로 이메일을 찾아주는 기능은 없다 — 아이디는 공개 정보라 남의 이메일 힌트가 새기 때문

## H-01 · Home › 아이템

공개로 등록된 아이템을 최신순으로 뿌린다.

- 검색바
- 카테고리 필터 — 상위 묶음(옷장·냉장고·집·생활용품) 칩을 먼저 보이고, 고르면 하위 카테고리가 펼쳐지는 2단 구조
- 그리드 보기 ↔ 리스트 보기 라디오 버튼
- 카드 탭 → H-02

## H-02 · Home › 아이템 상세

할 수 있는 것: 좋아요, 작성자 프로필로 이동, 팔로우.

## H-03 · Home › INMYIN 목록

- 상단: 전체 + 주요 카테고리 몇 개
- 정렬: 인기순 / 최신순 (인기 = 최근 24시간 좋아요 수)
- 카드 탭 → H-04

## H-04 · Home › INMYIN 상세

게시물 이미지 위의 아이템 영역(hotspot)을 탭하면 그 아이템 상세(M-14)로 간다. 삭제된 아이템이면 이미지는 그대로 보이고 탭해도 아무 일도 일어나지 않는다.

## H-05 · Home › 발견

사람을 찾는 탭. 필터 두 개.

| 필터 | 대상 | 정렬 |
| --- | --- | --- |
| 인기 | 전체 유저 | 최근 24시간 좋아요 수 |
| 추천 | 누적 좋아요 100 미만인 유저 | 최근 1시간 좋아요 수 |

둘 다 유저의 INMYIN 게시물과 아이디·팔로우 버튼을 보여준다.

## H-06 ~ H-08 · 타유저 프로필

팔로우 버튼, 프로필 공유 버튼. 팔로우·팔로잉 숫자를 누르면 모달(M-12a)이 뜬다. 그 사람의 인벤토리 · 아이템 모아보기 · INMYIN 게시물을 구경할 수 있다.

**비공개 아이템은 아예 보이지 않는다.** 저장은 칸 번호 그대로 두고, 읽을 때만 공개 아이템을 모아 다시 줄을 세운다.

## M-01 · My › 내 프로필

모바일에서 My의 기본 화면. 여기서 설정 · 인벤토리 · INMYIN 에디터로 갈라진다.
**웹에서는 프로필과 인벤토리가 한 화면에 같이 나오는 게 기본이다.**

## M-03 · My › 인벤토리 목록

인벤토리를 추가하고 고르는 화면. 추가 시 추천 4종 + "직접 만들기"를 보여준다.

- 베이직: 5개까지, 판당 25칸
- 프리미엄: 20개까지, 판당 50칸
- 한도에 닿으면 프리미엄 안내

## M-04 · My › 인벤토리 상세

격자가 나오고, 빈 칸을 누르면 두 가지로 채운다.

1. 새로 사진 찍어 아이템 등록하기 → M-06
2. 다른 인벤토리를 통째로 담기

**이미 등록된 아이템은 불러올 수 없다.** 실제 물건은 두 곳에 동시에 존재할 수 없기 때문이다. 옮기려면 짐싸기를 쓴다. 같은 이유로, 이미 다른 인벤토리 안에 들어가 있는 인벤토리도 또 불러올 수 없다. 한 줄로 이어지는 중첩은 5겹까지 (예: 집 › 방 › 가방 › 작은 가방 › 파우치).

### 새 아이템이 들어가는 자리

**항상 다음 빈 칸.** 첫 줄에 끼워 넣어 기존 아이템을 밀어내지 않는다. 자리가 바뀌면 "어디에 뭘 뒀는지"라는 이 앱의 핵심 가치가 무너진다.

추가 직후 처리:

- 새로 들어간 칸으로 자동 스크롤
- 그 칸을 약 1초간 강조 (테두리 또는 배경)

최신순으로 보고 싶을 때는 리스트 보기와 아이템 모아보기(M-13)가 있다. **격자는 자리 고정, 리스트는 최신순**으로 역할을 나눈다.

### 추가 버튼

- **+ 칸은 첫 번째 빈 칸에 하나만.** 나머지 빈 칸은 회색 그대로 둔다
- **+ 칸이 화면 밖으로 나가면 플로팅 버튼이 나타난다.** 하단탭 위 16px, 우측 16px. 둘 다 결과는 같다 — 다음 빈 칸에 추가
- **칸이 다 차면** + 칸 자리에 "칸이 가득 찼어요 · 프리미엄으로 늘리기"를 띄운다. + 를 그냥 없애면 기능이 사라진 줄 안다
- 하단에 `16/25` 같은 사용량 표시를 유지한다

### 칸 수에 따른 격자

| 칸 수 | 열 |
| --- | --- |
| 25 (베이직) | 3 |
| 50 (프리미엄) | 4 |
| 100+ | 5 |

빈 칸이 수십 개 이어지면 마지막 줄까지만 그리고, 그 아래는 "남은 칸 70개" 한 줄로 요약한다.

## M-05 · 짐싸기

우측 상단 버튼 → 인벤토리 두 개가 동시에 열린다. 한쪽에서 아이템을 선택하면 반대쪽으로 넘어가고 즉시 자동 저장된다.

- 한 번에 하나씩만 옮긴다. 다중 선택 없음
- 되돌리기 버튼 없음 — 반대쪽에서 다시 누르면 돌아온다
- 받는 쪽이 꽉 찼으면 "○○가 꽉 찼습니다. 이동이 불가합니다" 알림을 띄우고 이동하지 않는다

## M-06 · 아이템 촬영

실제 썸네일로 쓰일 영역 밖은 어둡게 마스크 처리되어 직사각형 프레임을 보여준다. 하단에 "갤러리에서 선택" 버튼.

**웹에서는 이 화면이 없다.** 데스크톱에서는 등록 버튼 자리에 "휴대폰에서 등록해 주세요" 알림을 띄운다.

## M-07 · 아이템 편집

- 배경 자동 제거 (누끼 따기)
- 글쓰기, 그리기
- 저장하기 → M-08

## M-08 · 아이템 정보 입력

| 필드 | 필수 | 형태 |
| --- | --- | --- |
| 아이템 이름 | ● | 한 줄 텍스트 |
| 간단한 설명 | ● | 여러 줄 텍스트 |
| 카테고리 | | 이 인벤토리에 내장된 고정 카테고리 중 선택 (custom 인벤토리면 이 필드 없음) |
| 개수 | | 숫자 |
| 공개 여부 | | 공개 / 비공개 토글 |
| 획득날짜 | | 날짜 |
| 유통기한 | | 날짜 |

## M-09 ~ M-11 · INMYIN 에디터

빈 캔버스에 올릴 수 있는 것: 내 인벤토리 속 아이템(배경 제거된 썸네일), 갤러리 사진, 스티커.
조작: 확대·축소, 회전, 위치 이동.

이미지 캡처(M-10) → 갤러리 저장 또는 포스팅(M-11).

저장 형태:

```
InmyinPost {
  imageUrl     // 납작된 최종 이미지 (피드 노출용)
  canvasJson   // 개체 목록 + 위치/크기/회전 (재편집용)
}
PostItem[] { postId, itemId, x, y, w, h }   // 탭 영역
```

## M-13 · 아이템 모아보기

인벤토리 구분 없이 아이템 전체를 최신순으로 본다. 내 프로필과 타유저 프로필 양쪽에 있다.

## V-01, V-02 · Like 탭

좋아요를 누른 것들이 모이는 탭. 상단이 아이템 / INMYIN 두 갈래.

- 아이콘과 이름은 북마크가 아니라 **하트**
- 검색과 카테고리 필터를 넣는다 (H-01과 같은 2단 구조)
- 좋아요 표시한 아이템은 내 인벤토리에 들어오지 않는다 — 내 것이 아니니까. UI에서 이 구분을 분명히 할 것
